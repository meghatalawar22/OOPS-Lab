## OOPS Concepts

### 1. Classes and Objects

**Class:**  
A class is a user-defined data type in C++ that groups data
members and member functions together. It acts as a blueprint
for creating objects.

**Object:**  
An object is an instance of a class. It is used to access the
data members and member functions defined in the class.

---

### 2. Constructors

A constructor is a special member function of a class that is
automatically called when an object is created. It is mainly
used to initialize the data members of an object.

---

### 3. Static Data Members

A static data member is a data member of a class that is shared
by all objects of that class. Only one copy of a static data
member exists for the entire class.

---

### 4. Destructors

A destructor is a special member function that is automatically
called when an object is destroyed. It is used to perform
cleanup operations before the object is removed from memory.
